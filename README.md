# Fingerprint Image Analysis Using 2D Fourier Transform

## Project Description
This project performs digital image processing on two fingerprint images using Python and Google Colab.

## Technologies Used
- Python
- Google Colab
- OpenCV
- NumPy
- Matplotlib

## Methodology
1. Read two fingerprint images.
2. Convert images into grayscale.
3. Apply 2D Fast Fourier Transform (FFT).
4. Calculate magnitude spectrum.
5. Calculate phase spectrum.
6. Display original images and frequency-domain results.

## Results
The original fingerprint images, magnitude spectra, and phase spectra are displayed using Matplotlib.

## Conclusion
Successfully implemented 2D Fourier Transform for fingerprint image analysis using Python.
